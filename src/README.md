# Редактор LV News Suite

Исходник разделён на последовательные части одной замкнутой области видимости: базовые функции, Rank Math, блоки, данные, панели, рабочая область. Файлы `.js.inc` не загружаются WordPress напрямую.

После изменений выполните `node tools/build-editor.mjs` и `node --check assets/editor.js`. Сборка не требует сторонних пакетов. WordPress загружает готовый `assets/editor.js`.

Публичные стили `assets/public.css` и стили контента редактора `assets/editor-content.css` сохранены из 1.3.0 без изменений ради совместимости оформления. Их переработка не входит в этот выпуск.
