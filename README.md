# LV News Suite

Плагин WordPress для редакции новостей благотворительного фонда «Люди и Верблюды».

Версия 1.5.1 объединяет визуальный редактор новостей, архив `/news/`, выбор главной новости, предпросмотр, SEO-инструменты, интеграцию с Rank Math и редакционный контроль готовности материала.

## Возможности

- отдельный тип записей и визуальный редактор новостей;
- фирменные блоки, H2/H3 и управление изображениями;
- архив новостей, отдельная страница материала и виджет для главной;
- ручной выбор главной новости;
- SEO-поля, canonical, Open Graph и JSON-LD;
- интеграция с Rank Math и синхронизация SEO-данных;
- предпросмотр для разных размеров экрана;
- проверка готовности и защита от конфликтов сохранения;
- диагностика и фоновые миграции данных.

## Требования

- WordPress 7.1 или новее;
- PHP 7.4 или новее;
- Rank Math — необязательная интеграция.

## Установка

1. Скачайте `lv-news-suite-1.5.1.zip` из [последнего релиза](https://github.com/bfcamel/lv-news-suite/releases/latest).
2. В WordPress откройте **Плагины → Добавить новый → Загрузить плагин**.
3. Выберите ZIP-файл, установите и активируйте плагин.
4. Перейдите в **Новости → Система новостей** и проверьте состояние обновления.

Перед обновлением рабочего сайта рекомендуется сделать резервную копию и проверить выпуск на копии сайта с фактическими версиями темы, Elementor и Rank Math.

Подробный порядок установки и проверки: [docs/INSTALL-AND-TEST-1.4.0.txt](docs/INSTALL-AND-TEST-1.4.0.txt).

## Счётчики

Откройте **Новости → Счётчики**, добавьте название и полный HTML/JavaScript-код каждого сервиса, включите нужные записи и сохраните. Настройки доступны администраторам с правом `unfiltered_html` (в Multisite — супер-администратору).

Вывод через `wp_footer` внизу архива и отдельных новостей, без изменения шаблонов Elementor. Начиная с 1.5.1 код выводится без дополнительных HTML-контейнеров, отступов и стилей плагина: невидимые счётчики LiveInternet/Метрики не должны создавать пустое место перед подвалом. Главная, блок `[lv_home_news]` и предпросмотр исключены. Код для обязательной вставки в `<head>` не поддерживается. [Описание выпуска](docs/RELEASE-NOTES-1.5.1.md).

## Проверка счётчиков

Только на одноразовой тестовой установке WordPress (тест создаёт записи и меняет настройки):

```sh
WP_LOAD_PATH=/path/to/wordpress/wp-load.php php tests/counters.php
python3 tools/build-release.py
```

## Разработка редактора

Исходный код редактора находится в `src/editor/` и собирается без сторонних пакетов:

```bash
node tools/build-editor.mjs
node --check assets/editor.js
```

После изменений собранный `assets/editor.js` необходимо добавить в коммит. Подробнее: [src/README.md](src/README.md).
