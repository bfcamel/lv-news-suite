Установка LV News Suite 1.4.0

Архив содержит обновление существующего плагина lv-news-suite, включая исправления 1.3.1. Промежуточная установка 1.3.1 не нужна.

1. Сохраните резервную копию базы данных и файлов сайта.
2. На тестовой копии сайта замените существующий плагин через «Плагины → Добавить → Загрузить плагин», выбрав lv-news-suite-1.4.0.zip и замену текущей версии. Не удаляйте существующие новости или страницу /news/.
3. Обновите открытые вкладки редактора, чтобы загрузился новый код. При наличии кеша очистите его штатным способом.
4. Проверьте главную, /news/, следующую страницу архива и /news/nam-nuzhny-zabotlivye-ruki/ на компьютере, планшете и телефоне. Сравните скриншоты до/после при одинаковой ширине, особенно карточки, главное фото, обтекание изображений и подвал.
5. Создайте черновик, сохраните текст и SEO, переоткройте его, проверьте предпросмотр и публикацию по расписанию. Проверьте права редактора и восстановление ревизии.
6. При включённом Rank Math не редактируйте локальные SEO meta сторонними REST-клиентами: активным владельцем этих полей является Rank Math. Локальные поля — резервная копия и данные ревизий.
7. Откройте «Новости → Система новостей». При обновлении старой схемы требуется работа WP-Cron. Если DISABLE_WP_CRON включён, нужен уже настроенный серверный запуск cron. При переходе с актуальной 1.3.0 повторная миграция не требуется.
8. После успешной проверки повторите замену на основном сайте. При необходимости отката используйте сохранённый архив 1.3.0; если менялись данные/выполнялась миграция, учитывайте также резервную копию базы.

В этой задаче рабочий сайт не изменялся. Браузер не смог проверить администраторскую политику доступа ни для bfcamel.ru, ни для локальных страниц. Поэтому утверждать, что визуальная проверка на рабочем сайте уже выполнена, нельзя. Локальная проверка равенства CSS и публичного HTML выполнена отдельно.
