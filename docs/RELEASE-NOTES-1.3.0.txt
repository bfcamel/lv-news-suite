LV News Suite 1.3.0 — Rank Math и целостность архива

Причина
=======

Предыдущая версия определяла наличие редактора Rank Math через
wp_script_is('rank-math-analyzer', 'registered') и несуществующий для текущего
Gutenberg handle rank-math-post-metabox. Rank Math регистрирует и подключает
свои редакторские assets в другом admin hook, поэтому проверка зависела от
порядка выполнения и могла возвращать false даже при включённых SEO Controls.

Кроме того, LV News Suite менял только собственные post meta. Gutenberg-версия
Rank Math хранит редактируемые SEO-данные в store `rank-math`, отмечает их как
dirtyMetadata и сохраняет отдельным REST-запросом rankmath/v1/updateMeta.
Обычный editPost() локальных meta не обновлял интерфейс и анализ Rank Math.

Исправлено
==========

1. Диагностика runtime
----------------------

Статус больше не вычисляется по случайно зарегистрированному script handle.
Сервер проверяет официальный список разрешённых типов записи Rank Math, а
браузер ждёт фактического появления store `rank-math` и rankMathEditor.refresh().
Отдельно показываются состояния загрузки, готовности, отключённых SEO Controls,
нехватки прав, частичной и аварийной загрузки.

2. Прямая синхронизация
-----------------------

Поля LV News Suite вызывают штатные actions Rank Math:

- updateTitle + updateSerpTitle;
- updateDescription + updateSerpDescription;
- updateKeywords;
- updateCanonicalUrl;
- updateFacebookTitle;
- updateFacebookDescription.

Изменение сразу появляется в интерфейсе Rank Math, попадает в dirtyMetadata и
участвует в следующем сохранении. Обратная подписка на store зеркалирует ручные
изменения Rank Math в локальные meta LV News Suite.

3. Пересчёт анализа
-------------------

После готовности runtime вызываются rankMathEditor.refresh() для content,
title, description и keyword, а затем action refreshResults(). Официальный
фильтр rank_math_content продолжает передавать анализатору текущий текст
Gutenberg. Неиспользуемый в JavaScript Rank Math фильтр rank_math_title удалён.

4. Надёжность сохранения
------------------------

Серверная сверка до/после REST-save сохранена как страховка от параллельных
запросов WordPress и Rank Math. Схема данных повышена до 6: при обновлении
существующие пары meta повторно сводятся, приоритет имеет уже заполненное
значение Rank Math. rank_math_seo_score не создаётся, не удаляется и не
подменяется LV News Suite.

5. Белая полоса перед подвалом `/news/`
----------------------------------------

На рабочей странице Elementor после #lvNewsArchive оставлял отдельный пустой
`p.wp-block-paragraph` с неразрывным пробелом. Абзац находился за пределами
бежевого контейнера и показывал белый фон темы непосредственно перед footer.
Точечное правило скрывает только этот последний пустой сосед shortcode, а фон
обёрток страницы архива теперь совпадает с фоном #lvNewsArchive.

Дополнительно итоговый HTML shortcode архива и блока новостей на главной
уплотняется между тегами. Это защищает разметку от позднего `wpautop` внутри
Elementor Text Editor, который на рабочей странице вставлял `<br>` и лишние
закрывающие `<p>` в ссылки, метаданные и карточки.

Совместимость
=============

Если Rank Math отключён, все SEO-поля и публичный резервный SEO-вывод LV News
Suite продолжают работать. Исправления изображений из 1.2.9 сохранены без
изменений.
