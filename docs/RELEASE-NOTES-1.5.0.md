## Счётчики на страницах новостей

В админке появился раздел **Новости → Счётчики**. Добавляйте несколько независимых счётчиков: у каждого есть название, полный HTML/JavaScript-код и переключатель включения. Счётчики можно удалять; изменения применяются после сохранения.

- Включённые счётчики выводятся внизу страниц архива, включая пагинацию и пустой архив, и отдельных новостей.
- Главная страница, блок `[lv_home_news]`, другие страницы, RSS, REST, AJAX и предпросмотр исключены.
- Сохранение доступно только администраторам с правом WordPress `unfiltered_html`; запрос защищён nonce.
- Код сохраняется без изменения JavaScript и не выполняется на странице настроек.
- По умолчанию список пуст: после обновления вставьте свои коды и сохраните настройки. При наличии кеша очистите его.

Скачайте `lv-news-suite-1.5.0.zip` из Assets и установите через загрузку плагина с заменой текущей версии. Вывод использует стандартный `wp_footer`, который должен вызываться темой. Коды сервисов, требующие размещения именно в `<head>`, для этих полей не подходят.

Проверено в изолированном WordPress 7.1 / PHP 8.5: сохранение нескольких кодов, права и nonce, экранирование админки, архив, пагинация, отдельная новость, исключение главной и предпросмотра, отключение и удаление. Проверка на рабочем сайте с фактической темой и Elementor не выполнялась.
