LV News Suite 1.2.0 — установка и проверка
===========================================

Перед установкой
----------------
1. Сделать резервную копию базы данных и папки текущего плагина.
2. Сохранить ZIP версии 1.1.2 для быстрого отката.
3. Старые новостные WPCode-сниппеты редактора / главной / архива / отдельной новости не должны одновременно работать с плагином.
4. НЕ отключать Universal Hero и Hero Rotation: они остаются отдельными компонентами.

Установка
---------
1. WordPress → Плагины → Добавить новый → Загрузить плагин.
2. Выбрать lv-news-suite-1.2.0.zip.
3. Подтвердить замену существующего «Люди и Верблюды — Новости».
4. Убедиться, что в списке один экземпляр плагина и версия 1.2.0.
5. Очистить кеш WordPress, Elementor и Autoptimize, если используются.

Система
-------
1. Открыть «Новости → Система новостей».
2. Проверить:
   - версия плагина 1.2.0;
   - схема данных 3;
   - маршруты 1;
   - /news/ найдена;
   - [lv_news_archive] присутствует;
   - опубликованная главная новость не более одной.
3. Убедиться, что старые lv_news, их ID, даты, тексты, изображения и URL сохранились.

Новый редактор
--------------
1. Открыть существующую опубликованную новость. Она должна редактироваться без требования переделывать старый текст.
2. Создать новый черновик.
3. Проверить боковую панель «Редактор новости».
4. Проверить латинский URL-ярлык на русском заголовке.
5. Выбрать тип новости.
6. Вставить текст из Word / Google Docs: структура абзацев, списков, жирного, курсива и ссылок должна оставаться редактируемой средствами Gutenberg.
7. Перетащить несколько блоков мышью.
8. Добавить обычное фото и галерею.
9. Добавить специальные блоки «Врезка», «Факт», «Кнопка».
10. Проверить шаблоны структуры.
11. Выбрать главное изображение, заполнить alt, изменить X/Y и масштаб — миниатюра кадра должна обновляться.
12. Проверить индикатор готовности.
13. Проверить Desktop / Tablet / Mobile в предпросмотре.
14. Сохранить черновик, дождаться автосохранения и проверить WordPress Revisions.

Проверка публикации
-------------------
1. Новый черновик без обязательного поля не должен публиковаться.
2. Обязательные поля: заголовок, анонс, основной текст, главное изображение, тип новости.
3. H1 внутри текста должен блокировать первую публикацию; H2/H3 разрешены.
4. Рекомендации по длине, alt и качеству изображения не должны блокировать публикацию.
5. После заполнения обязательных полей новость должна публиковаться нормально.

Главная новость
---------------
1. В редакторе включить «Главная новость» у опубликованного материала.
2. Проверить большую карточку в /news/ и первую большую карточку [lv_home_news].
3. Назначить другую новость главной — прежняя должна автоматически потерять признак.
4. Проверить действие «Сделать главной» на странице «Все новости».
5. Дублировать главную новость — копия должна быть черновиком и не должна стать главной.

Публичная часть
---------------
1. Главная: [lv_home_news] — большая + компактная карточка, кнопка «Все новости».
2. /news/ — внешний Universal Hero остаётся на месте; архив начинается ниже него.
3. /news/page/2/ — корректная пагинация, если новостей достаточно.
4. /news/page/1/ → 301 на /news/.
5. Заведомо несуществующая /news/page/999/ → 404.
6. /news/slug/ — Hero новости, автор, дата без времени, приблизительное время чтения, текст, изображения и «Другие новости».
7. Проверить desktop / tablet / mobile.

SEO
---
1. С Rank Math: на /news/ должен быть один canonical на текущую страницу архива.
2. /news/page/2/: canonical на /news/page/2/, rel=prev и при необходимости rel=next.
3. Отдельная новость: один canonical и одна сущность статьи / NewsArticle.
4. Проверить datePublished, dateModified, author, publisher, image.
5. Если в старой новости уже были ручные Rank Math title / description / canonical, первый обычный save 1.2.0 не должен их стереть.
6. Заполнить SEO-поля 1.2.0 и убедиться, что они применяются.

Стили и производительность
--------------------------
1. Архив и главная визуально не должны «прыгать» после загрузки изображений.
2. Фокус и масштаб главного изображения должны работать в карточках и Hero.
3. public.css должен загружаться на новостных страницах и там, где используется [lv_home_news].
4. В 1.2.0 не проверять старые inline style#lv-news-page-css / style#lv-single-news-css: CSS вынесен в отдельный файл.
5. Проверить отсутствие ошибок в консоли браузера.

Откат
-----
1. Загрузить сохранённый lv-news-suite-1.1.2.zip поверх 1.2.0 и подтвердить замену.
2. Очистить кеш.
3. Проверить главную, /news/ и отдельную новость.
4. Дополнительные meta-поля и option схемы 1.2.0 не изменяют post_content и могут безопасно остаться в базе; старая версия их игнорирует.
