LV News Suite 1.2.1 — patch release
===================================

Исправлено
----------
1. Выравнивание изображений в редакторе. Gutenberg больше не позиционирует left/right-фото относительно всей ширины canvas: корневой поток WYSIWYG ограничен шириной статьи 760 px, а выровненные изображения используют float внутри этой колонки.
2. Публичное отображение left/right-фотографий приведено к той же модели: ширина до 340 px и не более 46% колонки; на узких экранах float отключается.
3. H1 внутри текста исключён на трёх уровнях: интерфейс скрывает стабильные H1-кнопки, JS автоматически переключает core/heading level=1 на H2, сервер при сохранении нормализует H1 из Gutenberg, Classic/freeform HTML и REST. Единственный H1 страницы — заголовок новости.
4. Готовность стала объяснимой: рядом с процентом показываются все невыполненные проверки. Если обязательные поля заполнены, интерфейс отдельно сообщает, что публиковать можно, а до 100% остались рекомендации.

Совместимость
-------------
Патч обновляет 1.2.0 без миграции базы. DB schema остаётся 3, routes version — 1. Все существующие lv_news, URL и shortcodes сохраняются.
