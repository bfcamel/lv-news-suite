LV News Suite 1.2.7 — Rank Math analysis sync

Исправлено
==========

1. Устаревший SEO score Rank Math
-------------------------------
Ранее кнопка «Заполнить SEO автоматически» корректно записывала SEO meta, но в списке новостей мог оставаться старый rank_math_seo_score (например 9/100). Теперь любое изменение SEO из панели LV сначала помечает сохранённый score как требующий пересчёта. Если после REST-save входные данные анализа изменились, а score остался старым, сервер удаляет только устаревший score.

Плагин НЕ подставляет искусственный балл. Новый score по-прежнему вычисляет Rank Math своим анализатором.

2. Официальный Content Analysis API
----------------------------------
Интеграция подключена через wp-hooks + rank-math-analyzer. Актуальные title/content текущего Gutenberg editor передаются в анализатор Rank Math, после изменения материала и после Save вызывается rankMathEditor.refresh().

3. Фокусная ключевая фраза
--------------------------
Автозаполнение больше не копирует весь заголовок. Генерируется короткий непрерывный фрагмент 2–5 слов; начальные «мы», «нам», «наш», «это» и другие служебные слова удаляются, когда это не разрушает фразу.

Например:
«Нам нужны заботливые руки» -> «нужны заботливые руки».

4. Meta description
-------------------
Если автоматически созданное description не содержит фокусную фразу, она аккуратно добавляется в начало и итог по-прежнему ограничивается рекомендуемой длиной.

5. Двусторонняя совместимость
-----------------------------
Поля LV News Suite и основные поля Rank Math продолжают зеркалироваться через REST. Ручная правка непосредственно в Rank Math не должна откатываться старым локальным значением LV.

Совместимость
=============
