LV News Suite 1.2.0 — release notes
===================================

Назначение релиза
-----------------
1.2.0 превращает прежний набор редакционных улучшений в единое рабочее место для создания и публикации новостей без HTML.

Реализовано
-----------
1. WYSIWYG/Gutenberg-редактор с ограниченным набором подходящих для новости блоков.
2. Специальные блоки:
   - Врезка текста;
   - Выделенный факт;
   - Кнопка-ссылка.
3. Быстрые редакционные шаблоны:
   - обычная новость;
   - история подопечного;
   - событие;
   - сбор / просьба о помощи.
4. Единая боковая панель:
   - заголовок;
   - латинский slug;
   - тип новости;
   - анонс;
   - главное изображение;
   - alt;
   - фокус и масштаб изображения;
   - главная новость;
   - SEO / Open Graph;
   - предпросмотр;
   - чек-лист готовности.
5. Предпросмотр отдельной страницы в Desktop / Tablet / Mobile.
6. Использование штатных WordPress autosave, revisions и drag-and-drop.
7. Проверка перед первой публикацией: заголовок, анонс, основной текст, главное изображение и тип новости обязательны; дополнительный H1 запрещён.
8. Существующие опубликованные материалы не блокируются новой проверкой и не требуют миграции контента.
9. Главная новость остаётся единственной; при отсутствии ручного выбора используется последняя опубликованная.
10. Фильтры и быстрые действия в «Все новости»: тип, автор, главная, качество, дублирование и предпросмотр.
11. SEO-поля синхронизируются с Rank Math при заполнении. Пустые новые поля не стирают ранее настроенные значения Rank Math.
12. Резервный canonical / meta / JSON-LD работает и без Rank Math.
13. Архивная пагинация и canonical используют общий расчёт.
14. Схема данных повышена до 3; версия маршрутов остаётся 1.

Совместимость
-------------
Сохраняются lv_news, lv_news_type, [lv_home_news], [lv_news_archive], /news/, /news/page/N/, /news/slug/. Universal Hero и его ротация не включены в этот плагин и должны оставаться активными отдельно.

Примечание по стилям
--------------------
В 1.2.0 публичные стили вынесены в assets/public.css и подключаются как stylesheet. Поэтому старые диагностические проверки на наличие inline-тегов style#lv-news-page-css / style#lv-single-news-css больше не являются корректным критерием версии 1.2.0. Проверять нужно внешний вид и наличие lv-news-suite-public в подключённых стилях.

Проверки сборки
---------------
Перед упаковкой выполняются PHP lint всех PHP-файлов, node --check редакторского JS, проверка баланса CSS-скобок и проверка состава ZIP. Полноценная проверка поведения с конкретной темой, Elementor, Autoptimize и установленной версией Rank Math должна выполняться на WordPress после установки.
