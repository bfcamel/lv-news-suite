LV News Suite 1.2.4 — patch release

1. Heading palette
- Новый core/heading исключён из allowed blocks для lv_news. В slash inserter доступны только отдельные блоки H2 и H3.
- H1, H4, H5 и H6 не являются допустимыми уровнями внутри новости. Старый контент остаётся совместимым, а неподдерживаемые уровни нормализуются при сохранении.

2. Редакционные блоки
- «Лид / вступление» — крупный вводный абзац.
- «Фирменная врезка» — визуальный эквивалент фирменного span: border-left 2px #b71c1c; padding-left 14px; font-size 1.4em; font-weight 500; color #b71c1c.
- «Важная информация» — отдельный информационный box для условий, сроков и предупреждений.
- «Источник / примечание» — небольшая служебная подпись.
- Существующие «Врезка текста», «Выделенный факт» и «Кнопка-ссылка» сохранены.

3. Inserter и шаблоны
- Добавлена категория «Новости фонда».
- Добавлены keywords для быстрого поиска через «/».
- Боковая панель быстрых блоков и встроенные шаблоны переведены на H2/H3-систему.

База данных и маршруты не менялись: DB schema 4, routes 1.
