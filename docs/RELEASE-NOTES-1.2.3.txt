LV News Suite 1.2.3 — patch release

Исправления
===========
1. Архив /news/
- Убран визуальный зазор/цветная полоса над изображениями карточек.
- Media-контейнеры принудительно сбрасывают padding, line-height и border, которые могли приходить из темы/старых сниппетов.
- Изображение позиционируется абсолютным cover-слоем и всегда заполняет всю область карточки.

2. Gutenberg/WYSIWYG
- Причина неправильного alignright/alignleft была в iframe Gutenberg: editor.css стилизовал оболочку админки, но не сам документ внутри iframe.
- Добавлен отдельный assets/editor-content.css.
- CSS документа передаётся через block_editor_settings_all и дополнительно подключается JS-fallback внутри editor iframe.
- Левая/правая фотография ограничена текстовой колонкой 760 px и больше не уезжает к краю окна редактора.

3. Rank Math / SEO
- Добавлено собственное поле фокусной ключевой фразы с двусторонней синхронизацией rank_math_focus_keyword.
- Для пустых SEO title, description и Open Graph автоматически создаются корректные значения из заголовка и анонса/текста.
- Добавлена кнопка «Заполнить SEO автоматически» в панели редактора.
- Ручные значения Rank Math не стираются: миграция сначала импортирует существующие поля и только затем заполняет недостающее.
- DB schema: 4.

Примечание о SEO-score
======================
Rank Math рассчитывает свой числовой балл самостоятельно на основе фокусной фразы, title, description, URL и текста. LV News Suite не записывает фиктивный rank_math_seo_score. После синхронизации SEO откройте/сохраните новость, чтобы Rank Math выполнил актуальный анализ.
