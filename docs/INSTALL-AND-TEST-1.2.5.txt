LV News Suite 1.2.5 — установка и проверка
===========================================

Требования
----------
WordPress 7.1+
PHP 7.4+

Установка
---------
Установить ZIP поверх существующего плагина и подтвердить замену. Очистить кэш оптимизатора/страницы админки, если он используется.

Критический тест SEO
--------------------
1. Открыть существующую новость.
2. Раскрыть «SEO и соцсети».
3. Нажать «Заполнить SEO автоматически».
4. Запомнить SEO title и description.
5. Нажать «Сохранить».
6. Дождаться завершения Save.
7. Поля должны остаться заполненными.
8. Обновить страницу браузера — значения должны сохраниться.
9. В списке новостей/Rank Math проверить, что focus keyword/title/description доступны Rank Math.

Тест WordPress 7.1 editor
-------------------------
1. В пустом абзаце ввести /.
2. Core Heading/H1 не должен предлагаться среди разрешённых блоков.
3. Должны быть доступны «Заголовок раздела (H2)» и «Подзаголовок (H3)».
4. Проверить фирменные блоки и изображения внутри iframe редактора.
5. Проверить alignleft/alignright.

Тест изображений
----------------
Новая загрузка должна получить зарегистрированные размеры lv-news-*. На браузерах, где WordPress 7.1 включает client-side media processing, sub-sizes создаются в браузере; иначе WordPress автоматически использует серверную обработку. Старые вложения продолжают работать через fallback.
